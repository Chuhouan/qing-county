# 青縣 · Qing County

> 中国县域治理模拟游戏 · County Governance Simulation

**🧩 在线试玩：** [https://chuhouan.github.io/qing-county/](https://chuhouan.github.io/qing-county/)

---

## 简介

《青縣》是一款以真实中国县域治理为背景的文字策略模拟游戏。玩家以县委书记的身份，治理一座虚构但数据基于正定县的北方县城——**青县**。

这不仅仅是一个数字游戏。你需要在**经济发展、社会稳定、财政平衡、人事布局、上级关系、强权博弈**等多重维度之间权衡取舍。每一个决策都有代价，每一次提拔都有连锁反应。

> "郡县治，天下安。"

## 核心玩法

### 周回合约

游戏以 **1周 = 1回合** 推进。一个完整的游戏任期共5年（约260回合）。

每周流程：
1. 选择本周**关注领域**（经济/民生/稳定/党建/改革）
2. 处理本周**随机事件**（日常/信访/紧急/上级交办）
3. 系统自动更新：社会张力→经济活力→上级信任→派系动态→腐败风险→巡视巡查……
4. 每月底结算财政，每年底结算考核

### 玩家角色

- 玩家扮演 **县委书记陈志远**，初始38岁，可自选2个特质（如务实/放权/激进等）
- 核心资源：**精力**（每周可支配的行动点数）、**政治资本**（影响上级评价和常委会票数）
- 每周可执行：召开会议、批阅文件、下乡调研、干部谈话、跑上级等快速操作

## 子系统详解

### 🏛️ 经济系统（EconomicSystem）

以**三驾马车**（投资/消费/净出口）为核心的经济增长模型。

- **八大产业**：农业、工业、建筑业、批发零售、交通运输、住宿餐饮、金融、房地产
- GDP推导链：产业增加值→GDP→税收→转移支付→地方财政收入
- **财政系统**并入经济系统：含专项债、转移支付、债务率、自给率等
- 玩家可操作的**经济杠杆**：招商引资、基建投资、产业补贴、土地出让

### 👥 社会系统 v3（SocialSystem）

10个社会群体的状态机模拟，是游戏最复杂的子系统（~1370行）。

- **10大群体**：农民、产业工人、企业主、公职人员、知识分子、个体商户、农民工、退休人员、待业青年、宗教人士
- **双维度状态**：怨气（0-100）和动员度（0-100），决定集体行动等级
- **5级集体行动**：从"抱怨"到"大规模群体事件"
- **公共舆论系统**：舆情热点生成、传播、衰减
- **信访维稳一体化**：信访案件生成→化解→越级，与群体怨气双向驱动
- **维稳资源分配池**：信访化解/巡逻防控/矛盾排查/舆情监控四项分配
- **季节性事件**：春耕、防汛、开学季、年底欠薪
- **4项主动操作**：下访调研、矛盾排查、联席会议、民生工程

### 👔 人事系统（PersonnelSystem）

38名正定县真实官员，覆盖县四套班子。

- **四维属性**：能力（0-100）、忠诚（对书记）、野心（0-100）、关系网（朋友圈）
- **市管/县管分类**：县委常委属市管，部门局长属县管
- **5步任免流程**：动议→五人小组预审→常委会表决→报市委备案→人大任命
- 每步都有追责记录，任免程序不全会影响上级评价

### 🔗 派系系统 v2（FactionRelationshipSystem）

不设意识形态阵营，做权力关系网络（类似CK3封臣关系+FM更衣室小团体）。

- **六大派系**：书记系（自己人）、县长系（搭档/对手）、本土系（地头蛇）、空降系（带天线）、官僚系（办事的）、无派系（风向标）
- **派系关系矩阵**：书记系↔县长系竞争，本土系↔空降系对立
- **派系流动机制**：每位官员对各派系有亲和度（0-100），低于25退出，高于75加入
- **朋友圈连锁反应**：提拔/查处一个干部→朋友圈忠诚度/野心联动→派系格局演变
- **每周权力重算**：凝聚力漂移、关系向默认值回归

### ⭐ 上级关系系统（SuperiorRelationshipSystem）

县委书记的省、市两级上级关系网络。

- **核心数值**：信任度、印象分、政治资本、人情账本
- **6种玩家操作**：跑上级汇报、争取项目、请托办事、使用保护伞、递投名状、站队表态
- **5种随机事件**：交办任务、工作调研、紧急督办、晋升考察、巡查巡视
- **靠山体系**：可绑定省/市领导作为政治靠山，靠山倒则受牵连

### 💸 腐败系统（CorruptionSystem）

双刃剑系统：违规操作可快速推进项目，但累积被查风险。

- **7种腐败操作**：加速审批、违规减税、土地违规出让、压制报道、挪用资金、卖官鬻爵、虚报项目
- **4阶段调查流程**：匿名举报→纪委初步核实→立案调查→处分/司法
- 保护伞和上级关系可压下调查，但不能永远压下去
- 与巡视巡查系统双向耦合：巡视发现线索→移交纪委

### 🔍 巡视巡查系统（InspectionSystem）

生命周期型系统，一届任期触发1-2次。

- **4阶段全流程**：入驻准备（2-4周）→巡视进驻（2-4周）→问题反馈（1-2周）→整改落实（4-12周）
- **8大风险领域**：财政资金、工程建设、土地出让、选人用人、党的建设、生态环保、安全生产、乡村振兴
- **4种巡视风格**：雷霆手段（强发现力）、深挖细查、常规巡视、例行公事（弱发现力）
- **干部谈话机制**：每周约谈3-4名干部，派系属性影响谈话诚实度
- **玩家应对策略**：协作配合（发现率↑印象↑）、引导方向（暴露轻风险域）、消极应对（发现率↓印象↓）
- **巡视后果**：结果影响上级印象、政治资本、考核评分、社会张力
- 整改阶段可投入精力/财政资金逐项推进

### 📢 NPC/人大系统（NPCSystem）

35名县委常委 + 243名人代会代表。

- **常委会**：双月例会，支持率影响决策通过率
- **人代会**：每年审议政府工作报告、预算、人事任免
- **派系比例分配**：各派系常委按势力分配席位

### 🎯 国策树系统（TaskSystem）

类似钢4/Vic3的国策树机制。

- 每条国策需若干周完成，完成后解锁后续分支或获得永久加成
- 涵盖经济、民生、党建、治理等多个维度

### 📜 叙事系统（NarrativeSystem + PlotlineEngine）

关键事件自动生成叙事文本，通过跑马灯和浮动面板注入沉浸感。

- PlotlineEngine：管理多条叙事线索的触发条件和推进逻辑
- EpilogueGenerator：游戏结局时根据玩家表现生成结算文本

### 🤖 AI秘书（AISecretary）

有性格的AI秘书**陈守义**，提供：

- **叙事**：关键事件生成场景描述
- **决策建议**：每周议题给出支持/反对/中立的建议
- **月度简报**：每月结束时AI生成治理总结
- 无APIKey时降级为规则模板

### 📊 考核系统（EvaluationSystem）

每年年底的六维政绩考核：

- 经济发展、社会稳定、民生改善、党建成效、生态环保、安全生产
- 综合评分影响上级评价、晋升机会和最终结局

### 🛂 信访系统（PetitionSystem）

已归入SocialSystem v3一体化管理（见社会系统说明）。

## 快速开始

### 前置条件

- Node.js >= 18

### 启动

```bash
cd xianzhi
npm install
node server.js
```

浏览器打开 `http://localhost:3000` 即可游玩。

### 配置 AI 秘书（可选）

创建 `.env` 文件：
```env
AI_API_KEY=sk-your-api-key-here
AI_API_BASE=https://openrouter.ai/api/v1
AI_MODEL=deepseek/deepseek-chat
```

不配置也不影响游戏运行，AI秘书降级为规则模板。

## 数据来源

游戏基础经济/人口/产业结构数据取自 **正定县**（河北省石家庄市辖县）公开统计数据，并进行了适当简化与泛化处理。

## 技术栈

- **纯前端**：HTML5 + CSS3 + Vanilla JavaScript（无框架依赖）
- **后端**：Node.js + Express（静态服务 + AI API 代理）
- **AI 集成**：OpenAI 兼容接口（可接入任意大模型）
- **存储**：localStorage（游戏存档）
