## 简介

《青縣》是一款以真实中国县域治理为背景的文字策略模拟游戏。玩家以 **县委书记** 的身份，治理一座虚构但数据基于正定县的北方县城—— **青县**。

游戏目标是撑过 **5年任期**，在经济发展、社会稳定、财政平衡、人事布局、上级关系、派系斗争等多重压力下生存，争取获得上级认可并谋求晋升。

> "郡县治，天下安。"——但县委书记的椅子永远没那么好坐。

## 游戏循环

### 1周 = 1回合，一年48周（12月×4周），5年任期共约240回合。

### 每周流程

每周按以下顺序执行（共约27步）：

1. **安全初始化** — 补全省/县/玩家缺失的嵌套属性
2. **社会张力计算** — 失业率→通胀→维稳能力→自然衰减(0.10)→随机波动，总和作用于社会张力
3. **社会系统v3更新** — 群体怨气漂移、公共舆论更新、集体行动检测、信访案件推进
4. **上级关系系统更新** — 信任自然漂移（每周+信任向基准回归）、人情账本磨损、交办事项检查
5. **巡视巡查系统更新** — 触发检测/准备/进驻/反馈/整改各阶段推进
6. **经济活力计算** — 基准40 + GDP增长加成(+300%) + 失业惩罚(-200%) + 投资加成(+5)
7. **三状态相互影响** — 稳定度<30→经济-3；稳定度>70→经济+1；经济活力<20→张力+1.5；经济活力>80→张力-0.5
8. **治理路线修正** — 4条治理路线(工业/民生/生态/改革)的每周modifier生效
9. **特质修饰器生效** — 玩家特质对GDP增长/张力抵抗/腐败免疫等的每周影响
10. **玩家状态追踪** — 压力=张力×0.02+0.8+能力修正；精力每周基础恢复+15
11. **体制指标漂移** — 官僚效率±0.3、腐败指数向60回归
12. **上级信任漂移** — 基于绩效评分向基准回归
13. **地方威望更新** — 基于群体满意度加权
14. **随机事件触发** — 张力>60时30%概率触发，否则20%
15. **提前出局检测** — 健康归零(病故)、事故(0.1%/周)、免职(张力>90且上级<-30)
16. **腐败调查检测** — 根据风险值和随机数决定是否触发纪委调查
17. **派系系统每周更新** — 派系凝聚力漂移、亲和度漂移、派系流动检测
18. **官员能力值驱动** — 各官员能力对对应领域产生加成
19. **派系提案事件** — 6大派系可能提出项目提案
20. **国策树每周推进** — 正在执行的国策+1周进度
21. **当务之急** — 随机触发紧迫事项 + 过期检查
22. **叙事系统更新** — 关键事件的叙事文本生成
23. **每周简报生成** — 本周大事汇总
24. **经济/财政微调** — 月度经济指标的周级别同步

### 每月流程（每4周执行一次）

1. **月度经济结算** — GDP/三产分割/增长率/三驾马车/就业率/CPI全量计算
2. **月度财政结算** — 税收/转移支付/非税收入/支出/债务/财政健康度计算
3. **历史记录** — 关键指标存档用于图表
4. **月度事件触发** — 最多2个新事件
5. **季度人大监督** — 3/6/9/12月触发
6. **乡镇数据同步** — 乡镇级经济数据更新
7. **信访月报** — 月度信访案件统计
8. **上级关系月度更新** — 信任微调+人情磨损

### 每年流程（每12月执行一次）

1. **年度考核评估** — 六维政绩评分
2. **叙事年度检查** — 重要剧情节点
3. **预算审议** — 每年1月触发预算审批（重新设定预算分配）
4. **任期检查** — 满5年触发游戏结局

## 子系统详解

### 一、经济系统（EconomicSystem）

经济系统以 **三驾马车（投资C + 消费I + 政府支出G + 净出口NX）** 为核心增长模型，数据基于正定县真实统计。

#### GDP计算链

```
月GDP = 年GDP / 12
  → 三产分割（农业30% / 工业35% / 服务业35%）
  → 政策修正 × 增长因子 × 市场冲击 × (1 - 灾害因子)
  → 三驾马车法：Y = C + I + G + NX
  → 年化增长率：旧值×0.7 + 新值×0.3（平滑）
  → 同步到乡镇GDP
  → 更新就业率、城镇化率、CPI
```

#### 八大产业

农业、工业、建筑业、批发零售业、交通运输业、住宿餐饮业、金融业、房地产业

#### 财政系统（内置于EconomicSystem）

| 概念 | 说明 |
|------|------|
| **财政收入** | 税收（增值税/企业所得税/个人所得税/土地增值税等）+ 转移支付 + 非税收入 |
| **财政支出** | 人员工资 + 公用经费 + 项目支出 + 预备费 |
| **国库余额** | 上期结余 + 本月收入 - 本月支出 |
| **财政健康度** | 0-100，基于债务率、自给率、国库余额综合计算 |
| **债务率** | 隐性债务 + 显性债务 / 年收入 |
| **自给率** | 本地税收 / 总支出 |
| **征收率** | 玩家可调(0.3~1.0)，影响税收但影响社会满意度 |
| **节俭令** | 三档循环：正常→紧缩(-15%支出)→极简(-30%支出) |
| **跑部钱进** | 主动争取转移支付+30%，持续6月，上级信任-15 |

#### 预算科目（4项）

| 科目 | 说明 | 调整范围 |
|------|------|---------|
| 人员经费 | 工资/津贴 | ≥40% |
| 公用经费 | 办公/差旅/设备 | -50%~+100% |
| 项目支出 | 基建/民生工程 | -50%~+100% |
| 预备费 | 应急储备 | ≥5% |

#### 玩家经济操作

| 操作 | 说明 |
|------|------|
| 设置征收率 | 调整税收比率 |
| 预算调剂 | 四科目间调配资金 |
| 节俭令 | 紧缩/极简模式 |
| 跑部钱进 | 争取转移支付 |
| 土地出让 | 一次性收入但增加隐性债务 |
| 招商引资（UI按钮） | 提升经济活力 |

### 二、社会系统 v3（SocialSystem）

游戏最复杂的子系统（~1370行），管理10个社会群体、公共舆论、集体行动、信访维稳一体化。

#### 10大社会群体

| 群体 | 标签 | 关联派系 | 核心诉求 |
|------|------|---------|---------|
| farmer | 农民 | 本土系 | 土地/补贴/基础设施 |
| worker | 工人 | 县长系 | 就业/工资/劳动保护 |
| teacher | 教师 | 官僚系 | 工资/学校条件/编制 |
| merchant | 商户 | 本土系 | 税收/营商环境/摊位 |
| entrepreneur | 企业主 | 县长系 | 政策/贷款/审批效率 |
| retired | 退休干部 | 书记系 | 退休金/医疗/活动场所 |
| laidoff | 下岗职工 | 空降系 | 社保/再就业/低保 |
| student | 学生 | 无派系 | 教育质量/就业前景 |
| migrant | 外来务工 | 本土系 | 户籍/子女教育/权益 |
| townsfolk | 乡镇居民 | 本土系 | 公共服务/治安/环境 |

每个群体有 **怨气(0-100)** 和 **动员度(0-100)** 两个核心状态，以及若干属性：
- `baseGrievance` — 基础不满倾向
- `mobilization` — 当前动员程度
- `demands` — 诉求列表
- `leaders` — 群体领袖名单
- `satisfaction` — 满意度（影响怨气变化）
- `organization` — 组织化程度（影响动员速度）

#### 群体怨气驱动因素

```
怨气变化 = 基础漂移 + 经济影响 + 政策影响 + 事件冲击 - 民生投入衰减
```

- 失业率上升 → 工人/下岗职工/学生怨气↑
- 税收增加 → 商户/企业主怨气↑
- 公共服务改善 → 农民/乡镇居民怨气↓
- 腐败曝光 → 所有群体怨气↑

#### 5级集体行动

| 等级 | 名称 | 触发怨气 | 后果 |
|------|------|---------|------|
| 1 | 来信来访 | ≥5 | 张力+2，上级评价-1 |
| 2 | 集体上访 | ≥10 | 张力+5，上级评价-3 |
| 3 | 罢工/罢市 | ≥15 | 张力+8，经济活力-10，税收-15% |
| 4 | 堵路/集会 | ≥25 | 张力+15，经济活力-20，上级评价-8 |
| 5 | 群体事件 | ≥35 | 张力+25，经济活力-30，上级评价-15，可能触发免职 |

每级行动提供3种应对选项（批转/接访/搁置、疏导/承诺/公安、对话/安抚/处置、应急预案/驱散/上级介入等），选择影响后续发展。

#### 公共舆论系统

- `propagandaPower` — 宣传力量（影响舆论走向）
- `rumorRisk` — 谣言风险
- `transparency` — 信息透明度
- 舆论话题列表：每条有标题、倾向性、来源、影响群体、热度、衰减速率、严重程度
- 玩家可通过政策调整宣传力量和透明度

#### 维稳资源分配池

4个维度，总量100点，玩家自行分配：

| 维度 | 效果 |
|------|------|
| 信访化解 | 加速信访案件化解，降低越级风险 |
| 巡逻防控 | 降低集体行动触发概率和等级 |
| 矛盾排查 | 提前发现潜在问题，降低怨气积累速度 |
| 舆情监控 | 降低谣言风险，提前预警舆论热点 |

#### 玩家可操作的社会行动

| 操作 | 说明 | 消耗 |
|------|------|------|
| 下访调研 | 发现隐藏案件+怨气-5 | 精力15 |
| 矛盾排查 | 案件难度×0.85持续4周 | 精力20+政治资本8 |
| 联席会议 | 所有案件越级风险-10 | 精力10 |
| 民生微工程 | 定向解决群体关切 | 精力5+财政拨款 |
| 维稳资源分配 | 调整4维分配比例 | 无消耗 |

| 类别 | 范围 | 任免流程 |
|------|------|---------|
| 市管干部 | 县委常委、副县长 | 动议→五人小组→常委会→报市委审批→人大任命 |

#### 5步任免流程

```
第1步：动议 ── 提出任免建议，消耗政治资本5

第3步：常委会 ── 全体常委投票（基于派系+关系+五人小组态度）
第4步：报市委 ── 市管干部必经，基于上级信任计算通过率
第5步：人大任命 ── 政府组成部门负责人需人大表决
```

#### 派系流动机制

每位官员对各派系有 **亲和度（0-100）**：

- **退出**：对本派系亲和度 ≤ 25 → 自动退出至无派系，锁定48周不能重新加入
- **加入**：对某派系亲和度 ≥ 75 → 自动加入（取最高者）
- **可跳转**：退出一个派系后若对其他派系≥75，直接跳入而非先变无派系

亲和度变化来源：
- **自然漂移**：每周向基准值回归3%
- **朋友圈影响**：≥3个同派系朋友 → 每周+1
- **提拔**：同派系对本派系+3~5，敌对派系对本派系-2
- **查处**：本人对己方派系-15，同派系-5，敌对派对被查处方派系+3

#### 派系凝聚力

每派系有凝聚力值(0-100)，受以下因素影响：
- 领袖能力（领袖的能力值×0.3）
- 派系内官员亲密度平均值
- 派系间竞争压力（敌对派系强势时凝聚力上升）
- 成员被提拔/查处事件

凝聚力低→派系成员更容易被他派拉拢→可能跳槽

#### 派系提案池（14个）

各派系会随机提出项目提案（如本土系→道路修缮/农田水利/老旧小区改造），玩家需在常委会中推动或否决。

#### 玩家派系操作

| 操作 | 说明 |
|------|------|
| 查看派系概览 | 显示各派系成员/领袖/凝聚力/关系 |
| 查看官员档案 | 四维属性+朋友圈+亲和度 |
| 派系关系网 | 可视化关系网络（节点+边） |
| 修改派系关系 | 通过操作间接影响（提拔/查处/调离） |

---

### 五、上级关系系统（SuperiorRelationshipSystem）

模拟县委书记与上级的政治关系网络。

#### 上级构成

| 角色 | 说明 |
|------|------|
| 市委书记 | 直接领导，决定晋升推荐 |
| 市长 | 政府线领导，影响财政支持 |
| 组织部 | 影响干部任免审批速度 |
| 省厅部门 | 专项转移支付和项目审批 |

每位市级领导有：`name`, `style`(务实/政治/激进), `trust`, `lastMeeting`, `meetingCount`, `evaluation`, `faction`, `keyConcerns`, `pendingRequests`

#### 6种玩家操作

| 操作 | 说明 | 消耗 |
|------|------|------|
| 汇报工作 | 去市委当面向书记汇报 | 精力15 |
| 跑省进厅 | 去省厅争取项目和资金 | 精力20+差旅费40万 |
| 邀请调研 | 请领导来县里视察 | 精力10+接待费80万 |
| 电话沟通 | 电话联系维系关系 | 精力5 |
| 完成交办 | 完成上级布置的专项任务 | 精力10 |
| 还人情债 | 偿还之前欠下的人情 | 政治资本5 |

#### 9种随机上级事件

| 事件 | 选项数 | 说明 |
|------|--------|------|
| 市委书记来电 | 3 | 询问某领域工作 |
| 市委开会通知 | 2 | 参加/请假 |
| 组织部考察 | 3 | 晋升考察应对 |
| 上级督查 | 3 | 迎接/准备/回避 |
| 政治风向 | 4 | 传达上级精神 |
| 上级表扬 | 1 | 正面事件 |
| 上级要人 | 3 | 借调干部 |
| 财政压减 | 1 | 预算被削减 |
| 邻县比较 | 2 | 排名压力 |

#### 政治账本 + 靠山体系

- **人情账本**：帮过谁、欠谁人情，可动用政治资本偿还
- **靠山绑定**：可绑定省/市领导作为政治靠山
- **靠山倒台**：靠山一旦出问题，玩家受影响

### 六、腐败系统（CorruptionSystem）

双刃剑系统：违规操作可快速获得资源，但累积被查风险。

#### 7种腐败操作（按玩家腐败等级解锁）

| 操作 | 需要等级 | 风险 | 收益 |
|------|---------|------|------|
| 加速审批 | 0 | +3 | 精力-5，政治资本+2 |
| 违规减税 | ≥10 | +8 | 企业关系+5，政治资本+5 |
| 土地违规出让 | ≥20 | +15 | 企业关系+8，政治资本+10 |
| 压制报道 | ≥30 | +7 | 政治资本+3 |
| 挪用专项资金 | ≥40 | +20 | 国库+500万 |
| 卖官鬻爵 | ≥50 | +18 | 政治资本+8 |
| 虚报项目套取资金 | ≥60 | +25 | 国库+1000万 |

#### 调查流程

```
风险累积 → 匿名举报(风险>60+15%概率) → 纪委调查(风险>80+10%概率)
  → 保护伞判定 → 压下(保住了) / 查实(游戏结束)
```

防御机制：
- **保护伞**：上级领导庇护，可压下调查但消耗保护伞资源
- **廉洁能力**：高廉洁度→风险自然下降
- **上级关系**：高信任度→调查被压下概率更高

#### 与巡视系统联动

- 巡视组发现严重线索 → 调用 `corruptionSys.receiveInspectionClue()` → 直接增加调查风险
- 巡视反馈等级为"严重" → 纪委启动初步核实

---

### 七、巡视巡查系统（InspectionSystem）

生命周期系统，一届任期触发1-2次。

#### 触发机制

- **第一次**：第2月**必触发**
- **后续**：每次巡视结束后1-2年后再次触发窗口，40%概率
- 触发概率受上级信任度（信任低→概率高）、全县腐败指数影响

#### 4阶段全流程

```
入驻准备(2-4周) → 巡视进驻(2-4周) → 问题反馈(1-2周) → 整改落实(4-12周)
```

**阶段1：入驻准备**
玩家可选择应对策略：
- 自查自纠（主动暴露小问题，上级印象+20）
- 掩盖问题（临时抹平漏洞，但若被发现后果加倍）
- 调离敏感干部（降低曝光概率，但得罪干部及派系）

**阶段2：巡视进驻**
- 每周干部谈话（3-4人），派系影响谈话诚实度
- 8大风险领域每周检查发现进度
- 随机事件（举报信/上访/突击检查等）
- 第1周弹出**应对策略选择**（配合/引导/消极），后续通过UI面板调整

**阶段3：问题反馈**
- 反馈等级：一般(绿) / 较重(黄) / 严重(红)
- 严重线索移交纪委（触发腐败系统调查）
- 玩家可选择回应态度：诚恳接受/解释说明/轻描淡写
- 影响上级印象、政治资本、考核评分

**阶段4：整改落实**
- 自动生成整改清单，每项需N点努力值
- 每周自动推进1点，每2周弹出操作选项
- 可投入精力(10点+20努力值)或财政资金(200万+35努力值)加速
- 提交验收报告，结果：通过/有条件通过/不通过

#### 8大风险领域

| 领域 | 风险值来源 |
|------|-----------|
| 财政资金 | 基础随机+隐藏债务加成+违规支出加成 |
| 工程建设 | 基础随机+违规项目数加成 |
| 土地出让 | 基础随机+违法转让标记+30 |
| 选人用人 | 基础随机+腐败指数加成 |
| 党的建设 | 基础随机（低权重） |
| 生态环保 | 基础随机+污染指数加成 |
| 安全生产 | 基础随机+社会张力加成 |
| 乡村振兴 | 基础随机 |

#### 4种巡视风格

| 风格 | 持续周数 | 发现效率 | 特点 |
|------|---------|---------|------|
| 雷霆手段 | 3周 | 1.5倍 | 最高效迅猛 |
| 深挖细查 | 5周 | 1.3倍 | 最全面细致 |
| 常规巡视 | 4周 | 1.0倍 | 中规中矩 |
| 例行公事 | 3周 | 0.7倍 | 最容易糊弄过去 |

#### 巡视后果

| 结果 | 上级印象 | 信任 | 政治资本 | 考核 | 社会张力 |
|------|---------|------|---------|------|---------|
| 通过 | +25 | +15 | +10 | +5 | -2 |
| 有条件通过 | 0 | -5 | -5 | -5 | +2 |
| 不通过 | -35 | -25 | -20 | -15 | +5 |
| 未正式验收 | -15 | -10 | -10 | -10 | 0 |

### 八、考核系统（EvaluationSystem）

每年年底进行六维政绩考核。

#### 六维考核指标

| 维度 | 数据来源 | 权重 |
|------|---------|------|
| 经济发展 | GDP增长率、财政收入、经济活力 | 25% |
| 社会稳定 | 社会张力、群体事件次数、信访量 | 20% |
| 民生改善 | 就业率、公共服务满意度、人均收入 | 20% |
| 党建成效 | 基层组织建设、党内纪律 | 15% |
| 生态环保 | 污染指数、环保考核 | 10% |
| 安全生产 | 事故发生率、安全隐患整改率 | 10% |

综合评分影响：
- 上级评价和晋升机会
- 巡视巡查结果（巡视不通过→扣分）
- 年度绩效奖金（财政条线）

### 九、NPC/人大系统（NPCSystem）

#### 常委会（35名常委）

- 双月例会，12种议程（批准预算/通过决议/人事任免等）
- 派系比例分配，支持率影响决议通过
- 常委派系立场 + 个人关系 + 五人小组态度 → 投票结果

#### 人代会（243名代表）

- 每年审议政府工作报告、财政预算、人事任免
- 罢免分权：局长→常委会(35人)，县长→人代会(243人)
- 一府两院报告满意度投票

#### 游说系统

- 每名代表有投票意愿（基于派系立场+关系）
- `lobbyBias`≥10时噪声±2
- 可逐个游走代表，剩余人数可视化

### 十、国策树系统（TaskSystem）

类似钢4/Vic3的国策树。

- 每条国策需若干周完成（自动推进）
- 完成后解锁后续分支或获得永久加成
- 涵盖经济、民生、党建、治理等维度
- 可同时推进多条国策

### 十一、叙事系统（NarrativeSystem + PlotlineEngine + EpilogueGenerator）

| 组件 | 功能 |
|------|------|
| NarrativeSystem | 监听9种事件总线消息，生成叙事文本 |
| PlotlineEngine | 管理多条故事线，按条件触发/推进/分支 |
| EpilogueGenerator | 游戏结局时生成5年任期总结文本 |
| NarrativeMemory | 记录已发生的叙事事件，防止重复触发 |

叙事文本三处注入：面板气泡 + 跑马灯 + 事件日志。

| 月度简报 | 每月底AI生成治理总结 |
| 降级模式 | 无API Key时使用规则模板 |

## 快速开始

### 前置条件
- Node.js >= 18

### 启动
```bash
cd xianzhi
npm install
node server.js
```
浏览器打开 `http://localhost:3000` 即可游玩。

### 配置 AI 秘书（可选）
创建 `.env` 文件：
```env
AI_API_KEY=sk-your-api-key-here
AI_API_BASE=https://openrouter.ai/api/v1
AI_MODEL=deepseek/deepseek-chat
```
不配置也可正常游戏，AI秘书降级为规则模板。
